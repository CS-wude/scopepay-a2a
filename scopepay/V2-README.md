# ScopePay implementation

Use the [root setup and verification instructions](../README.md). Start the reproducible workspace with `node scopepay/market-preview.mjs`; configure your own model to use `npm run scopepay:local`.

The observer (`npm run scopepay:start`), generic marketplace and confirmed-contract workflow have distinct behavior and acceptance boundaries. Select payment and model adapters explicitly. See the root report link for the evaluated scope.
